# Tasks Tracker

- By Dee Daryani
- A simple todo list app built with HTML, CSS and JavaScript for Step8Up Bootcamp Week-4 Assignment.

## Features

- Add tasks by typing and pressing Enter or clicking Add
- Mark tasks as done with the checkbox
- Edit a task by clicking the pencil icon
- Delete a task by clicking the bin icon
- Tasks are saved in the browser so they survive a page refresh
